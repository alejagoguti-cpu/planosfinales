# Planos finales · Hotel La Fontana

Sitio público del proyecto del Piso 2 del Hotel Estelar La Fontana, con planos arquitectónicos y láminas técnicas exportadas individualmente desde Revit.

- Sitio: https://alejagoguti-cpu.github.io/planosfinales/
- Descargas PDF: https://alejagoguti-cpu.github.io/planosfinales/planos-redes.html

Los PDFs técnicos se encuentran en `assets/planos/redes/` y su listado público se genera desde `manifest.json`.
